# bryan-sky

Adapted from Bryan Chung's Shadertoy, with his permission. Original can be found at [https://www.shadertoy.com/view/wX3BDM](https://www.shadertoy.com/view/wX3BDM). Note that some features are currently missing, including support for Shadertoy's `iMouse` shader input. To change the view direction, modify the coefficients for `lookDir` in the code.
